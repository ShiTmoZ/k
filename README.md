## 🔬 مبانی علمی و تحقیقات اعصاب‌شناختی (Scientific Foundations)

پلتفرم **NEUROSHIFT** برخلاف برنامه‌های کلیشه‌ای و سطحی که با شمارنده‌های ثانیه‌ای وسواس فکری را تشدید می‌کنند، به عنوان یک **کنسول مهندسی شناختی بالینی** طراحی شده است:

### ۱. حذف ثانیه‌شمار زجرآور (Ironic Process Theory — Daniel Wegner)
نگاه کردن مداوم به ثانیه‌ها و دقیقه‌ها، کورتکس پیشانی را در وضعیت پایش دائمی موضوع نگه می‌دارد و بر اساس تحقیقات پروفسور دانیل ونگر، خود به محرک شماره یک لغزش تبدیل می‌شود. در این سیستم، **شاخص یکپارچگی عصبی (Neural Integrity Index)** مبتنی بر یک میانگین متحرک ۳۰ روزه محاسبه می‌شود.

### ۲. مصونیت در برابر اثر «به جهنم» مارلات (Anti-Marlatt Effect — G. Alan Marlatt)
در اپلیکیشن‌های سنتی، یک لغزش کل استریک را صفر می‌کند که طبق مطالعات اعتیاد بالینی منجر به پرخوری رفتاری شدید (Binge Episode) می‌شود. در NEUROSHIFT، ساختار سیناپسی ساخته‌شده با یک بار اشتباه از بین نمی‌رود؛ امتیاز سیستم تنها به اندازه یک افت حاد موقت (۱۲ الی ۱۸ واحد) کاهش می‌یابد و بیش از ۷۰٪ دستاوردهای نورونی حفظ می‌شود.

### ۳. شبیه‌سازی دینامیک پروتئین فاکتور رونویسی ΔFosB و گیرنده‌های D2
* **فاکتور رونویسی $\Delta\text{FosB}$ (Nestler et al.):** نیمه‌عمر این پروتئین در نورون‌های مخطط مغز حدود ۹ روز است و با گذر روزهای پاکی به‌صورت نمایی پاکسازی می‌شود.
* **گیرنده‌های دوپامین $D_2R$ (Volkow et al.):** کاهش شدید تراکم در حالت اعتیاد و بازیابی مجدد با تابع اشباع ($65\%$ در یک ماه و $>90\%$ در ۹۰ روز).

### ۴. رهگیر شناختی استروپ (Stroop ACC Saturation Engine)
مینی‌گیم تداخل رنگ و معنا مستقیماً قشر کمربندی قدامی (Anterior Cingulate Cortex) و قشر پیشانی پشتی‌جانبی (dlPFC) را درگیر می‌کند و با اشغال ظرفیت حافظه کاری، امکان تصویرسازی ذهنی جنسی را از نظر فیزیولوژیک قطع می‌کند.

### ۵. تنفس فیزیولوژیک هاب‌من (Cyclic Physiological Sigh)
بر اساس تحقیقات دکتر آندرو هاب‌من و دکتر دیوید اشپیگل (Cell Reports Medicine, 2023): دو دم پیاپی از بینی برای باز کردن کامل حبابچه‌های فروریخته ریه و یک بازدم طولانی از دهان، گیرنده‌های فشار قفسه سینه را فعال کرده و با ارسال پالس به عصب واگ، ضربان قلب را فوراً کاهش می‌دهد.

## 🛠️ معماری فنی (Technical Architecture)

```
ShiTmoZ/k/
├── .github/workflows/
│   └── build-windows.yml       # خط لوله GitHub Actions برای بیلد خودکار نصاب ویندوز
├── lib/
│   ├── neuroModel.js           # فرمول‌های ریاضی محاسبات عصب‌شناختی (D2R, DeltaFosB, NII, Circadian)
│   └── db.js                   # دیتابیس امن محلی با node:sqlite داخلی بدون نیاز به کامپایل خارجی
├── public/
│   ├── index.html              # رابط کاربری لوکس OLED Dark Bento با سینک آنی تلمتری
│   └── favicon.svg             # آیکون سیناپسی بهینه‌شده
├── server.js                   # سرور پرسرعت REST API با ماژول بومی Node.js
├── main.js                     # رانر اپلیکیشن دسکتاپ ویندوز با Electron
├── package.json                # وابستگی‌ها و تنظیمات بیلد electron-builder
├── vercel.json                 # کانفیگ استقرار آنی روی پلتفرم ابری Vercel
└── README.md                   # مستندات جامع علمی و توسعه
```

## 📡 اندپوینت‌های REST API

| متد | آدرس | شرح کارکرد |
| :--- | :--- | :--- |
| `GET` | `/api/status` | دریافت تلمتری زنده، امتیاز NII، درصد گیرنده D2، تراکم PFC و وضعیت ریسک شبانه‌روزی |
| `GET` | `/api/dopamine/simulation` | دریافت مختصات ریاضی منحنی دوپامین (هموستاز پایه، سقوط اعتیادی، و مسیر رشد) |
| `POST` | `/api/emergency/stroop` | ثبت عملکرد آزمون استروپ (زمان واکنش و دقت) و ارتقای امتیاز PFC |
| `POST` | `/api/emergency/sigh` | ثبت دوره‌های تنفس فیزیولوژیک و فعال‌سازی تنظیمی پاراسمپاتیک |
| `POST` | `/api/emergency/friction` | ثبت چک‌لیست اصطکاک محیطی (نور، خروج از اتاق، آب سرد) |
| `GET` | `/api/blackbox` | دریافت تاریخچه حوادث ثبت‌شده در جعبه سیاه به همراه تگ‌های تشخیصی |
| `POST` | `/api/blackbox` | ثبت سانحه جدید، تحلیل ریشه‌ای (Root Cause Analysis) و دریافت پروتکل مقابله فوری |
| `GET` | `/api/settings` | دریافت مشخصات پروفایل و ترجیحات رفتاری |
| `PUT` | `/api/settings` | به‌روزرسانی تنظیمات و فاز اهداف در دیتابیس محلی |

## 🚀 نحوه اجرا و استقرار

### ۱. اجرای سرور وب تحت شبکه محلی
```bash
# کلون ریپازیتوری
git clone https://github.com/ShiTmoZ/k.git
cd k

# اجرای سرور بومی (بدون نیاز به پکیج خارجی)
node server.js
```
سپس در مرورگر به آدرس `http://localhost:3000` مراجعه کنید.

### ۲. بیلد نسخه دسکتاپ ویندوز (.exe)
کافیست در گیت‌هاب برنچ `main` را پوش کنید؛ خط لوله **GitHub Actions** به صورت خودکار نسخه پرتابل و فایل نصبی ویندوز x64 را در بخش Artifacts تولید می‌کند.

برای اجرای لوکال در محیط توسعه دسکتاپ:
```bash
npm install
npm run desktop
```

### ۳. استقرار ابری در Vercel
مخزن را در پنل کاربری Vercel اضافه کنید؛ سیستم به طور خودکار رابط کاربری را با شبکه جهانی لبه (Edge CDN) مستقر می‌کند.
